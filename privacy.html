Command Centre

Privacy policy

Last updated 12 November 2026.

Command Centre is a personal tool. Its developer is its one user. This page says what the tool does with that person's Google data.

What it reads

With the user's consent, Command Centre reads Gmail messages and Google Calendar events through Google's APIs. Both permissions are read-only: gmail.readonly and calendar.readonly.

How it uses the data

The tool builds a daily brief for the user: mail that needs a reply, payments and deadlines, and the day's calendar. It drafts suggested replies for the user to review. It sends no mail and changes nothing in the Google account.

Command Centre uses Google user data for these features and for nothing else.

Where the data lives

Mail and calendar data stay on the user's own computer and in the user's own backups. The macOS keychain holds the Google access grant. Command Centre has no server.

Who else receives it

To summarise messages and draft replies, the tool sends the text of selected messages to an AI model provider, Anthropic. It sends a short digest of the brief to the user's own phone over WhatsApp.

Nobody else receives the data. The developer does not sell it and does not share it for advertising.

Deleting data and removing access

The data stays until the user deletes it. The user can delete the local files at any time and can remove the tool's access at myaccount.google.com/permissions.

Contact

Send questions to the support email shown on the Google consent screen.

About these pages

These pages set no cookies, run no scripts and load nothing from other sites. GitHub hosts them and may log visits under its own privacy statement.
